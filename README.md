# 🏦 Bank Application

A simple **Bank Application** developed using **HTML, CSS, and JavaScript**. This project allows users to create a basic bank account and perform simple banking transactions such as deposit, withdrawal, and balance checking.

## 📌 Features

* Create a Bank Account
* Enter Customer Name and Account Number
* Deposit Money
* Withdraw Money
* Check Account Balance
* Insufficient Balance Validation
* Basic Input Validation
* Simple and User-Friendly Interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Structure

Bank-Application/
│
└── bank.html

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `bank.html` file.
3. Open it in any web browser.
4. Enter customer details.
5. Create an account.
6. Use the Deposit, Withdraw, and Check Balance options.
